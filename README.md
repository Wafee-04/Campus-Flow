# Campus Flow

**Campus Flow** is a web-based campus management platform designed to make everyday university activities and information more accessible to students, faculty members, and university administrators.

## Project Overview

Campus Flow aims to bring different campus-related services into one centralized platform. It will help users stay informed about campus announcements, discover events, access campus facilities, and communicate issues to the appropriate authorities.

## Planned Features

- **User Management:** Role-based access for students, faculty members, administrators, and maintenance staff.
- **Announcements:** Share important university updates with relevant user groups.
- **Campus Facilities:** View information about campus buildings, rooms, and facilities.
- **Events:** Publish and manage campus events.
- **Clubs:** Explore clubs and manage memberships.
- **Complaints:** Submit and track campus-related complaints.

*Features are subject to change as development progresses.*

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL / MariaDB
- **Development Environment:** XAMPP
- **Version Control:** Git and GitHub

## Setup Instructions

1. Install XAMPP.
2. Clone this repository into your XAMPP `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Import the database SQL file from the `Database` folder using phpMyAdmin.
5. Configure the database connection in the `Config` folder.
6. Open the project in your browser:

   `http://localhost/CampusFlow/`
